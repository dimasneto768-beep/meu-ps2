04 / PRÓXIMOS PASSOS

O que falta para jogar

  1. Publicar esta interface no GitHub Pages.
  2. Testar o emulador separadamente no Safari e verificar suporte real a toque.
  3. Encontrar uma integração web permitida pelo projeto do emulador.
  4. Conectar os botões virtuais à API de controle do emulador e testar um jogo próprio/legítimo.
